# Jungle Dash — Endless Runner

A Temple Run-inspired endless runner made with vanilla HTML, CSS, and JavaScript. It uses a custom canvas scene and original simple game graphics.

## Run it
1. Download or extract the project folder.
2. Open `index.html` in a modern browser.
3. Press **Start Running**.

No build tools or libraries are required. Google Fonts are used for typography; the game itself works without them.

## Controls
- **Left / A:** move one lane left
- **Right / D:** move one lane right
- **Up / W / Space:** jump over rocks
- **Down / S:** slide under gates
- **Mobile:** swipe left/right/up/down

## Features
- Three-lane endless runner
- Coins, obstacles, score, speed multiplier, and best score
- Speed gradually increases over time
- Keyboard and touch controls
- Game-over and restart flow
- Best score stored locally in the browser

## Files
- `index.html` — layout and game HUD
- `style.css` — responsive visual design
- `script.js` — canvas rendering, movement, collision, scoring, and controls

## Customization
Change obstacle spawn rates and speed progression in `script.js`. Edit colors and layout in `style.css`.
